# 클린 데이터 라벨러

기획서 `기획.md`를 바탕으로 만든 Python + Arcade 교육형 타이쿤 게임 프로토타입입니다.
부스 체험용으로 전체 화면에서 실행되며, 모니터 해상도에 맞춰 화면 전체에 표시됩니다.

오늘의 프로젝트는 **학교 수업용 AI 학습 도우미(교육용 · 비상업)** 입니다. 카드 정답은 모두 이 이용 목적을 기준으로 정해져 있습니다.

카드 데이터는 `card.json`에서 불러옵니다. 카드 내용을 추가하거나 수정한 뒤 게임을 다시 실행하면 자동으로 반영됩니다. 실행 시 필수 필드와 `difficulty(1~3)`, `penalty(0 이상)` 등의 형식도 검사합니다.

## 실행

PowerShell에서 프로젝트 폴더를 연 뒤 실행합니다.

uv를 사용하면 Python 3.12가 없는 환경에서도 필요한 버전을 설치할 수 있습니다.

```powershell
uv python install 3.12
uv venv --python 3.12
uv pip install -r requirements.txt
uv run --python 3.12 main.py
```

프로젝트의 `.python-version` 파일에 Python 3.12가 지정되어 있어 uv가 프로젝트 버전을 자동으로 인식합니다.

```powershell
.\venv\Scripts\python.exe main.py            # 부스용: 전체 화면
.\venv\Scripts\python.exe main.py --window   # 점검용: 창 모드
```

Arcade가 설치되지 않은 새 환경이라면 다음을 먼저 실행합니다.

```powershell
pip install -r requirements.txt
```

## 부스 PC용 실행 파일 만들기

부스 PC에 Python을 설치하지 않아도 되도록 실행 파일을 만들 수 있습니다.

```powershell
uv pip install --python venv\Scripts\python.exe -r requirements-build.txt
.\venv\Scripts\python.exe tools\build_exe.py
```

`dist\CleanDataLabeler` 폴더가 만들어지면 폴더를 통째로 부스 PC에 복사하고 `run_booth.bat`을 실행합니다. `card.json`과 소리 파일은 exe 옆에 있으므로 부스에서도 수정할 수 있습니다.

- 새 PC에서 처음 실행할 때는 백신 검사 때문에 켜지는 데 1분 정도 걸릴 수 있습니다. 두 번째부터는 몇 초면 켜집니다.
- 실행 파일 점검: `CleanDataLabeler.exe --window --smoke-test`는 창 모드로 3초 실행 후 스스로 종료합니다.

## 부스 현장 체크리스트

행사 전날 또는 당일 시작 전에 부스 PC에서 확인합니다.

- [ ] `run_booth.bat`으로 실행해 전체 화면으로 켜지는지 (처음 실행은 1분 정도 걸릴 수 있음)
- [ ] 모니터 해상도·비율 확인. 16:9가 아니면 화면이 늘어나 보이므로 모니터 설정을 16:9로 맞춤
- [ ] 마우스 클릭과 1·2·3 키, ← → 키가 모두 동작하는지
- [ ] 소리 크기: 주변 소음에 맞게 PC 음량 조절, 필요하면 `F9`로 끄기
- [ ] 한 판 끝까지 플레이해 결과 화면, TOP 10 이니셜 입력까지 확인
- [ ] 테스트로 남은 랭킹 지우기: 게임을 `Ctrl+Shift+Q`로 끄고 `ranking.json` 삭제 후 다시 실행
- [ ] 진행 요원 키 공유: `Ctrl+Shift+Q` 종료, `F5` 처음 화면, `F9` 소리, `F11` 전체 화면
- [ ] PC 절전·화면 보호기 끄기 (Windows 설정 → 전원), 알림 끄기(방해 금지 모드)
- [ ] 키보드의 Windows 키로 바탕화면이 열릴 수 있으므로 진행 요원이 가까이 있기

## 조작

- 메뉴: `SPACE` 또는 `ENTER`로 시작, `T`로 튜토리얼
- 튜토리얼: 1페이지에서 `SPACE` / `ENTER` / `→`로 업그레이드 설명 보기, `←`로 이전 페이지
- 게임: 컨베이어 카드 클릭 또는 `←` / `→`로 카드 선택 → 키보드 숫자열 또는 숫자 키패드 `1 승인` / `2 정제` / `3 제외`
  - 카드를 고르지 않고 숫자를 누르면 서버에 가장 가까운 카드가 먼저 선택됩니다.
  - `ESC`: 일시정지 (`ESC` 계속하기, `M` 메뉴로 나가기)
- 업그레이드 (단축키 또는 버튼 클릭)

  | 키 | 업그레이드 | 비용 | 효과 |
  |---|---|---:|---|
  | `Q` | 워터마크 스캐너 | 300 | 저작권 신호 라벨과 붉은 테두리 표시 |
  | `W` | 개인정보 탐지기 | 400 | 개인정보 신호 라벨 표시 |
  | `E` | 편향 감지기 | 600 | 편향 신호 라벨 표시 (탐지기 3종이 모두 있으면 "신호 없음"도 표시) |
  | `R` | 데이터 버퍼 확장 | 450 | 컨베이어 속도 30% 감소 |
  | `A` | 라이선스 확인 봇 | 500 | 라이선스 이용 조건 한 줄 요약, 출처 신뢰도 표시 |
  | `S` | 자동 비식별화 | 700 | 서버에 도착한 개인정보 카드를 승인 대신 자동 정제 (틀릴 수 있음, 점수 없음) |
  | `D` | AI 자동 승인 모델 | 800 | 안전한 카드 중 40%를 대신 승인 (점수·예산 절반) |
  | `F` | AI 판단 도우미 | 1,000 | 복합 위험 카드에 추천 행동 표시 (85% 정확) |
- 결과 화면: `R` 재시작, `ESC` 메뉴

## 부스 운영

| 키 | 기능 |
|---|---|
| `Ctrl` + `Shift` + `Q` | 게임 종료 (부스 모드에서는 Alt+F4나 창 닫기로 꺼지지 않음) |
| `F5` | 언제든 처음 화면(메뉴)으로 |
| `F9` | 소리 켜기 / 끄기 |
| `F11` | 전체 화면 / 창 모드 전환 |

- 방치 시 자동 복귀: 결과 화면 40초, 튜토리얼 60초, 일시정지 60초 동안 입력이 없으면 메뉴로 돌아갑니다.
- 게임 중 방치: 45초 동안 입력이 없으면 "아직 플레이 중인가요?" 화면으로 멈추고, 20초 안에 ESC를 누르지 않으면 메뉴로 돌아갑니다.
- 이니셜 금지어: 영문·한국어 욕설 약어 등 부적절한 이니셜은 랭킹에 저장되지 않습니다. 목록은 `main.py`의 `BLOCKED_NAMES`에서 고칠 수 있습니다.
- 오류 대비: `run_booth.bat`으로 실행하면 게임이 오류로 꺼졌을 때 3초 뒤 자동으로 다시 켜집니다. 오류 내용은 `error.log`에 남습니다. `Ctrl+Shift+Q`로 끄면 다시 켜지지 않습니다.
- 라운드 단계: 적응(0~25초) → 기본 검수 → 혼합 데이터(60초~) → 편향 관리(100초~) → 고속 처리(140초~) → 데이터 러시(마지막 10초). 단계가 바뀔 때 화면에 안내가 나오고, 단계 주제에 맞는 카드가 더 자주 나옵니다. 데이터 러시에는 점수 2배 보너스 카드가 빠르게 들어옵니다.
- 적응 단계: 게임 시작 후 25초 동안 나온 카드는 도구가 없어도 위험 신호가 자동 표시됩니다.
- 오늘의 랭킹: 등급이 먼저, 같은 등급이면 점수 순으로 오늘의 TOP 10을 메뉴 화면에 보여 줍니다. TOP 10에 들면 영문 이니셜 3글자를 입력합니다(30초 동안 입력이 없으면 저장하지 않고 넘어감). 기록은 `ranking.json`에 저장되며, 날짜가 바뀌면 새 랭킹이 시작됩니다. 랭킹을 지우려면 게임을 끈 뒤 이 파일을 삭제합니다.
- 결과 화면: 등급과 최종 AI 신뢰도(정확도 40% + 신뢰 지표 평균 60%), 사용한 도구, 그리고 내가 고른 데이터로 학습한 AI의 결과물(챗봇 답변, 그림 생성, 인물 생성)을 보여 줍니다. 각 지표가 70 이상이면 안전한 결과, 낮으면 문제가 있는 결과가 나옵니다.
- 소리: 효과음과 배경음은 `tools/make_sounds.py`로 직접 합성한 것이라 저작권 문제가 없습니다. 소리를 바꾸려면 이 파일을 고친 뒤 다시 실행하면 `assets/sounds/`의 파일이 새로 만들어집니다. 마지막 10초에는 빠른 배경음으로 바뀝니다.

카드의 위험 신호(저작권·개인정보·편향)는 적응 단계(처음 25초)가 지나면 해당 탐지 도구를 구입해야 표시됩니다. 도구가 없을 때는 제목, 출처, 라이선스를 읽고 판단합니다. 세 탐지 도구를 모두 갖추면 신호가 없는 카드는 "신호 없음"으로 표시됩니다.

카드가 오른쪽 AI 학습 서버에 도착하면 검수 없이 자동 승인됩니다. 자동 승인된 카드는 결과가 안전해도 점수와 예산을 받지 못하고, 위험 데이터였다면 감점과 지표 하락이 발생합니다. 처리한 카드의 정답과 해설은 왼쪽 아래 "직전 카드 해설"에서 확인할 수 있습니다.
