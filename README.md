# 클린 데이터 라벨러

기획서 `기획.md`를 바탕으로 만든 Python + Arcade 교육형 타이쿤 게임 프로토타입입니다.
부스 체험용으로 전체 화면에서 실행되며, 모니터 해상도에 맞춰 화면 전체에 표시됩니다.

오늘의 프로젝트는 **학교 수업용 AI 학습 도우미(교육용 · 비상업)** 입니다. 카드 정답은 모두 이 이용 목적을 기준으로 정해져 있습니다.

카드 데이터는 `card.json`에서 불러옵니다. 카드 내용을 추가하거나 수정한 뒤 게임을 다시 실행하면 자동으로 반영됩니다. 실행 시 필수 필드와 `difficulty(1~3)`, `penalty(0 이상)` 등의 형식도 검사합니다. 형식이 틀리면 게임이 켜지지 않고 `error.log`에 몇 번째 카드가 문제인지 남깁니다. 제목 앞의 카드 번호(예: `"001 직접 그린 나무"`의 `001`)는 카드를 찾고 관리하기 위한 것이라 게임 화면에는 표시되지 않습니다.

글꼴은 `assets/fonts`의 [IBM Plex Sans KR](https://github.com/IBM/plex)(SIL Open Font License 1.1, `assets/fonts/OFL.txt`)을 게임과 함께 배포해 씁니다. 부스 PC에 글꼴을 설치하지 않아도 되고, 글꼴 파일이 없으면 맑은 고딕으로 표시됩니다.

## 실행

PowerShell에서 프로젝트 폴더를 연 뒤 실행합니다.

uv를 사용하면 Python 3.12가 없는 환경에서도 필요한 버전을 설치할 수 있습니다.

```powershell
uv python install 3.12
uv venv --python 3.12
uv pip install -r requirements.txt
uv run --python 3.12 main.py
```

프로젝트의 `.python-version` 파일에 Python 3.12가 지정되어 있어 uv가 프로젝트 버전을 자동으로 인식합니다.

```powershell
.\venv\Scripts\python.exe main.py            # 부스용: 전체 화면
.\venv\Scripts\python.exe main.py --window   # 점검용: 창 모드
```

Arcade가 설치되지 않은 새 환경이라면 다음을 먼저 실행합니다.

```powershell
pip install -r requirements.txt
```

## 부스 PC용 실행 파일 만들기

부스 PC에 Python을 설치하지 않아도 되도록 실행 파일을 만들 수 있습니다.

```powershell
uv pip install --python venv\Scripts\python.exe -r requirements-build.txt
.\venv\Scripts\python.exe tools\build_exe.py
```

`dist\CleanDataLabeler` 폴더가 만들어지면 폴더를 통째로 부스 PC에 복사하고 `run_booth.bat`을 실행합니다. `card.json`과 소리 파일은 exe 옆에 있으므로 부스에서도 수정할 수 있습니다.

- 새 PC에서 처음 실행할 때는 백신 검사 때문에 켜지는 데 1분 정도 걸릴 수 있습니다. 두 번째부터는 몇 초면 켜집니다.
- 실행 파일 점검: `CleanDataLabeler.exe --window --smoke-test`는 창 모드로 3초 실행 후 스스로 종료합니다.

## 부스 런처 (한 PC에서 세 게임)

부스 노트북 4대는 각각 세 게임을 모두 돌립니다. 실행 파일 폴더에 `booth.json`이 있으면 `run_booth.bat`이 게임 1·2·3을 고르는 시작 화면(런처)을 띄웁니다. 고른 게임이 꺼지면 런처 화면으로 돌아옵니다.

1. 세 게임 폴더를 나란히 둡니다: `Booth\CleanDataLabeler`, `Booth\data_packet-runner`, `Booth\password_guardian`
2. `CleanDataLabeler` 폴더의 `booth.example.json`을 `booth.json`으로 복사하고, PC 이름과 다른 두 게임의 이름·설명·실행 파일 경로를 고칩니다. 경로는 `CleanDataLabeler` 폴더 기준이고 `"command": "self"`는 이 게임입니다. Python으로 실행하는 게임은 `"command": "python"`(PC에 설치된 Python, 또는 가상환경의 `python.exe` 경로), `"args"`에 실행할 파일, `"cwd"`에 게임 폴더를 적습니다.
3. `run_booth.bat`을 실행합니다.

| 화면 | 키 | 동작 |
|---|---|---|
| 런처 | `1` `2` `3` 또는 클릭 | 게임 실행 |
| 런처 | `Ctrl` + `Shift` + `Q` | 부스 프로그램 전체 종료 |
| 이 게임의 메뉴 | `ESC` | 런처로 돌아가기 |
| 이 게임 어디서나 | `Ctrl` + `Shift` + `Q` | 런처로 돌아가기 |

- 다른 게임이 0이 아닌 종료 코드로 끝나거나 실행 파일을 찾지 못하면 런처에 빨간 안내가 나오고, 다시 고를 수 있습니다.
- `booth.json`의 `pc_name`(8글자 이내)은 이 게임의 랭킹판에 "PC 1 오늘의 TOP 10"처럼 표시됩니다. 랭킹은 PC마다 따로 저장됩니다.
- `booth.json`이 없으면 지금처럼 이 게임만 실행됩니다.
- 다른 게임 제작자에게 전달할 조건은 '부스 게임 런처 연동 안내' 문서에 정리되어 있습니다.

## 부스 현장 체크리스트

행사 전날 또는 당일 시작 전에 부스 PC에서 확인합니다.

- [ ] `run_booth.bat`으로 실행해 전체 화면으로 켜지는지 (처음 실행은 1분 정도 걸릴 수 있음). 실행 파일 폴더에서는 `CleanDataLabeler.exe --window --smoke-test`로 먼저 점검
- [ ] 모니터 해상도·비율 확인. 16:9(또는 16:10)를 권장. 4:3·5:4 모니터에서도 글자는 상자 안에 맞춰지지만 도형이 옆으로 눌려 보임
- [ ] 화면 글자가 IBM Plex Sans KR로 보이는지 (`assets/fonts` 폴더가 exe 옆에 있어야 함)
- [ ] 마우스 클릭과 1·2·3 키, ← → 키가 모두 동작하는지. 숫자 키패드를 쓰면 NumLock 켜기
- [ ] 한/영 키를 눌러 한글 상태로 바꾼 뒤에도 `T`(튜토리얼), `Q`·`W`(업그레이드), 이니셜 입력이 되는지. 안 되면 한/영 키로 영문 상태로 돌려 두기
- [ ] 소리 크기: 주변 소음에 맞게 PC 음량 조절, 필요하면 `F9`로 끄기
- [ ] 한 판 끝까지 플레이해 결과 화면, TOP 10 이니셜 입력, 오답 복습(`→`)까지 확인
- [ ] 테스트로 남은 랭킹 지우기: 게임을 `Ctrl+Shift+Q`로 끄고 `ranking.json` 삭제 후 다시 실행 (행사 전날 남긴 기록은 날짜가 바뀌면 자동으로 빠짐)
- [ ] `card.json`을 고쳤다면 `--window`로 한 번 켜서 확인. 형식이 틀리면 `run_booth.bat`이 다시 켜지 않고 안내 문구를 띄움
- [ ] 진행 요원 키 공유: `Ctrl+Shift+Q` 종료, `F5` 처음 화면, `F7` 짧은 체험(90초), `F9` 소리, `F11` 전체 화면
- [ ] PC 절전·화면 보호기 끄기 (Windows 설정 → 전원), 알림 끄기(방해 금지 모드), 행사 중 Windows 업데이트 자동 재시작 미루기
- [ ] 키보드의 Windows 키로 바탕화면이 열릴 수 있으므로 진행 요원이 가까이 있기

## 조작

- 메뉴: `SPACE` 또는 `ENTER`로 시작, `T`로 게임 소개·튜토리얼
- 튜토리얼(3쪽): ① 이 게임은? AI는 데이터로 배웁니다 ② 데이터 카드 읽는 법 ③ 업그레이드. `SPACE` / `ENTER` / `→`로 다음 쪽, `←`로 이전 쪽, `ESC`로 메뉴
- 게임: 컨베이어 카드 클릭 또는 `←` / `→`로 카드 선택 → 키보드 숫자열 또는 숫자 키패드 `1 승인` / `2 정제` / `3 제외`
  - 카드를 고르지 않고 숫자를 누르면 서버에 가장 가까운 카드가 먼저 선택됩니다.
  - `ESC`: 일시정지 (`ESC` 계속하기, `M` 메뉴로 나가기)
- 업그레이드 (단축키 또는 버튼 클릭)

  | 키 | 업그레이드 | 비용 | 효과 |
  |---|---|---:|---|
  | `Q` | 워터마크 스캐너 | 300 | 저작권 신호 라벨과 붉은 테두리 표시 |
  | `W` | 개인정보 탐지기 | 400 | 개인정보 신호 라벨 표시 |
  | `E` | 편향 감지기 | 600 | 편향 신호 라벨 표시 (탐지기 3종이 모두 있으면 "신호 없음"도 표시) |
  | `R` | 데이터 버퍼 확장 | 450 | 컨베이어 속도 30% 감소 |
  | `A` | 라이선스 확인 봇 | 500 | 라이선스 이용 조건 한 줄 요약, 출처 신뢰도 표시 |
  | `S` | 자동 비식별화 | 700 | 서버에 도착한 개인정보 카드를 승인 대신 자동 정제 (틀릴 수 있음, 점수 없음) |
  | `D` | AI 자동 승인 모델 | 800 | 안전한 카드 중 40%를 대신 승인 (점수·예산 절반) |
  | `F` | AI 판단 도우미 | 1,000 | 복합 위험 카드에 추천 행동 표시 (85% 정확) |
- 결과 화면: `R` 재시작, `ESC` 메뉴

## 부스 운영

| 키 | 기능 |
|---|---|
| `Ctrl` + `Shift` + `Q` | 게임 종료 (부스 모드에서는 Alt+F4나 창 닫기로 꺼지지 않음) |
| `F5` | 언제든 처음 화면(메뉴)으로 |
| `F7` | 짧은 체험 모드 전환: 한 판 3분 ↔ 90초 (다음 판부터 적용, 대기 줄이 길 때) |
| `F9` | 소리 켜기 / 끄기 |
| `F11` | 전체 화면 / 창 모드 전환 |

- 방치 시 자동 복귀: 결과 화면 40초, 튜토리얼 60초, 일시정지 60초 동안 입력이 없으면 메뉴로 돌아갑니다.
- 대기 화면: 메뉴가 30초 동안 방치되면 지나가는 관람객을 위한 소개 슬라이드(AI와 데이터 소개, 문제 있는 AI 예시, 오늘의 TOP 10, 좋은 AI 예시)가 7초마다 넘어갑니다. 아무 키나 누르거나 클릭하면 메뉴로 돌아옵니다.
- 짧은 체험 모드(`F7`): 한 판이 90초가 되며, 라운드 단계와 카드 속도도 같은 비율로 빨라집니다. 메뉴에 노란 글씨로 현재 시간이 표시됩니다.
- 오답 복습: 결과 화면에서 `→` 키나 "오답 복습" 버튼을 누르면 가장 최근에 틀린 카드 3장의 정답과 해설을 보여 줍니다.
- 이니셜 입력: 키보드로 입력하거나 화면의 A~Z 자판을 클릭해 입력할 수 있습니다.
- 게임 중 방치: 45초 동안 입력이 없으면 "아직 플레이 중인가요?" 화면으로 멈추고, 20초 안에 ESC를 누르지 않으면 메뉴로 돌아갑니다.
- 이니셜 금지어: 영어 욕설·성적 표현·혐오 표현·자해 표현, 한국어 욕설의 로마자 약어, 한글 자판 위치로 친 욕설(예: 한글 자판대로 '시발'을 치면 `TLQ`) 98개는 랭킹에 저장되지 않고 "사용할 수 없는 이니셜" 안내가 나옵니다. 이미 저장된 기록도 금칙어 이니셜이면 랭킹판에 보이지 않습니다. 목록은 `main.py`의 `BLOCKED_NAMES`에서 고칠 수 있습니다.
- 오류 대비: `run_booth.bat`으로 실행하면 게임이 오류로 꺼졌을 때 3초 뒤 자동으로 다시 켜집니다. 오류 내용은 `error.log`에 남습니다. `Ctrl+Shift+Q`로 끄면 다시 켜지지 않습니다. `card.json` 형식 오류는 다시 켜도 같으므로 반복하지 않고 안내 문구를 띄운 채 멈춥니다. `run_booth.bat`은 `CleanDataLabeler.exe`, `.venv`, `venv` 순서로 실행할 게임을 찾습니다.
- 한글 입력 상태: 게임 창에서는 입력기(IME)를 꺼 두어, 방문객이 한/영 키를 눌러도 영문 단축키와 이니셜 입력이 동작합니다.
- 라운드 단계: 적응(0~25초) → 기본 검수 → 혼합 데이터(60초~) → 편향 관리(100초~) → 고속 처리(140초~) → 데이터 러시(마지막 10초). 단계가 바뀔 때 화면에 안내가 나오고, 단계 주제에 맞는 카드가 더 자주 나옵니다. 데이터 러시에는 점수 2배 보너스 카드가 빠르게 들어옵니다.
- 적응 단계: 게임 시작 후 25초 동안 나온 카드는 도구가 없어도 위험 신호가 자동 표시됩니다.
- 오늘의 랭킹: 등급이 먼저, 같은 등급이면 점수 순으로 오늘의 TOP 10을 메뉴 화면에 보여 줍니다. TOP 10에 들면 영문 이니셜 3글자를 입력합니다. 3글자를 모두 채워야 저장되고(`ENTER` 또는 저장 버튼), `ESC`로 건너뛰거나 30초 동안 입력이 없으면 저장하지 않고 넘어갑니다. 기록은 `ranking.json`에 저장되며, 날짜가 바뀌면 새 랭킹이 시작됩니다. 랭킹을 지우려면 게임을 끈 뒤 이 파일을 삭제합니다.
- 결과 화면: 등급과 최종 AI 신뢰도(정확도 40% + 신뢰 지표 평균 60%), 사용한 도구, 그리고 내가 고른 데이터로 학습한 AI의 결과물(챗봇 답변, 그림 생성, 인물 생성)을 보여 줍니다. 각 지표가 70 이상이면 안전한 결과, 낮으면 문제가 있는 결과가 나옵니다.
- 소리: 효과음과 배경음은 `tools/make_sounds.py`로 직접 합성한 것이라 저작권 문제가 없습니다. 소리를 바꾸려면 이 파일을 고친 뒤 다시 실행하면 `assets/sounds/`의 파일이 새로 만들어집니다. 마지막 10초에는 빠른 배경음으로 바뀝니다.

카드의 위험 신호(저작권·개인정보·편향)는 적응 단계(처음 25초)가 지나면 해당 탐지 도구를 구입해야 표시됩니다. 도구가 없을 때는 제목, 출처, 라이선스를 읽고 판단합니다. 세 탐지 도구를 모두 갖추면 신호가 없는 카드는 "신호 없음"으로 표시됩니다.

카드가 오른쪽 AI 학습 서버에 도착하면 검수 없이 자동 승인됩니다. 자동 승인된 카드는 결과가 안전해도 점수와 예산을 받지 못하고, 위험 데이터였다면 감점과 지표 하락이 발생합니다. 처리한 카드의 정답과 해설은 왼쪽 아래 "직전 카드 해설"에서 확인할 수 있습니다.
