AI 윤리 체험 부스 - 실행 방법

1. START_BOOTH.exe 를 더블클릭하면 게임 선택 화면(런처)이 켜집니다.
   (처음 켤 때는 1분 정도 걸릴 수 있습니다)
2. 숫자 1, 2, 3 또는 화면을 눌러 게임을 고릅니다.
3. 부스를 닫을 때: 게임 선택 화면에서 Ctrl + Shift + Q

다른 폴더(CleanDataLabeler, PacketRunner, PasswordGuardian)는 열지 않아도 됩니다.
PC 이름은 CleanDataLabeler 폴더의 booth.json 에서 "pc_name"을 바꿉니다(선생님).
